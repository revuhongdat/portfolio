Kho Vũ Khí Công Nghệ

Hệ sinh thái công nghệ linh hoạt từ Core Data đến Frontend.

🐍

Python / Odoo ERP

Nắm vững kiến trúc MVC, bảo mật ACL/Record Rules. Thành thạo Model Inheritance, cron jobs tự động và xử lý Data Migration quy mô lớn.

☕

Java & Frontend/Mobile

Nền tảng Core Java/Spring Boot tốt. Trực tiếp tham gia dựng UI web (ReactJS, NextJS) và phát triển di động đa nền tảng (React Native).

🔗

Thiết kế API Tích Hợp

Cấu trúc các endpoint REST/JSON độ trễ thấp tối ưu cho ứng dụng Mobile. Sử dụng Webhook để đồng bộ đơn hàng hai chiều (vd: Pancake, Zalo OA).

🐘

PostgreSQL & DB

Khả năng tổ chức thiết kế CSDL (PostgreSQL, MySQL), viết query có tính tối ưu cao (Domain query) giải nén hiệu suất các trang view phức tạp.
